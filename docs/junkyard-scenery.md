# Endless junkyard scenery

The generated transparent atlas supplies all Earth scenery, including the launch area: distant scrap towers, warm buildings, pavement, and foreground junk. The supplied launch illustration has been removed because it did not align with the scrolling layers. The Canvas renderer reflects neighboring strips to share edge pixels, overlaps them by one pixel to avoid subpixel cracks, and moves each depth layer at its own horizontal camera speed. Small scrap clusters use a coordinate hash, so retracing a flight shows the same decorations. Only visible tiles are drawn and atlas/prop canvases are cached once. There is no generation request during play.

Asset: public/assets/junkyard-parallax-atlas.png (1536 x 1024). Generated with the built-in imagegen tool using the supplied launch illustration as a style reference. The historical prompt below records its former path; that illustration is no longer shipped or loaded. The delivered atlas uses unequal bands despite the equal-band request; verified source boundaries are 0, 337, 641, 821, and 1024 pixels. These are recorded in config.groundScene.atlasRows rather than assuming equal rows. All four bands contain real transparent pixels.

Configuration: src/config.ts groundScene. Rendering: src/ground-scene.ts. Earth scenery is drawn behind gameplay; the nearest foreground is drawn after the character and below the ground plane, before radar/HUD. The Moon keeps its existing surface. Artwork is visual only; collision ground remains y=0. The ground extends indefinitely using reusable art; larger landmarks can repeat.

Verification: npm.cmd run build; npm.cmd run check. With Vite running, node tests/scenery-browser.mjs http://127.0.0.1:5174 uses installed Windows Chrome, a temporary profile, and DevTools port 9337. It verifies alpha in each atlas band and captures actual aiming/launch frames plus isolated scenery at origin, left/right, a fractional tile position, a distant coordinate, altitude, and mobile width. Screenshots are saved in artifacts/scenery. The isolated scenery previews use a white character-height marker. The harness ignores the existing favicon.ico 404; it fails on other logged errors and runtime exceptions. This is a browser smoke check, not a complete flight or balance playtest.

All bands span full width and meet their respective left/right edge with compatible shapes for horizontal repetition. Keep layers completely separate, no overlap between rows. Use entire width, no border. Actual alpha transparency.
