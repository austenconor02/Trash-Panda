# Clouds, collection, and satellite salvage

Earth has three cloud depths with horizontal parallax factors 0.18, 0.34, and 0.56, gentle simulation-time drift, stable placement in either travel direction, and an atmospheric fade below orbit. `src/cloud-scene.ts` loads and alpha-trims six painted sprites once. There are no per-frame image readbacks or new canvases. The generated alpha atlas is `public/assets/junkyard-cloud-atlas.png`; it also appears behind the menu tablet.

Coin and scrap magnets capture pickups into 0.34–0.50-second curved flights. Higher upgrades increase radius and shorten travel time. Captured sprites survive chunk unloading without regenerating duplicates. Rewards are credited once when the sprite arrives, followed by a 0.22-second shrinking coin and expanding glint. Normal direct pickups use the same finishing animation. Pause freezes these effects; reset clears them.

See [payday details](payday-music-fuel.md) for the separate per-stat earning rates and slower receipt sequence, and [satellite details](orbital-satellites.md) for top-face salvage versus damaging side/upward impacts.

Validation: `npm.cmd run check`, `npm.cmd run build`, and isolated Chrome playtesting. `tests/sky-collection-salvage.mjs` covers cloud stability, magnet timing and single credits, captured chunk persistence, moving top contacts, unchanged side/upward hits, first-contact ordering, and exact sequential receipt math. Browser evidence and screenshots are in `artifacts/polish-pass`; the final cloud screenshots are `artifacts/playtest/clouds-painted-launcher.png` and `artifacts/playtest/clouds-painted-flight.png`. Mobile receipts were checked at 390px and 320px. These checks verify runtime behavior and visuals; they do not constitute a full progression rebalance.

## Cloud generation

Generated with the built-in image generation tool through the imagegen skill. The PNG's generated transparency is preserved. Prompt:

> Use case: stylized-concept. Asset type: production transparent 2D cloud sprite atlas for Trash Panda, a hand-painted cartoon junkyard raccoon launch game. Generate one PNG atlas, landscape 1536x1024 composition, EXACTLY six isolated clouds, in a strict 2-column by 3-row uniform grid of equal cells. Each cell contains one distinct wide fluffy cloud centered inside it with generous fully transparent margin on all sides; all cloud tips remain inside their own cell. Clouds must never touch each other. Warm cream and pale peach sunlit upper edges, desaturated slate blue and teal-gray shaded undersides, gentle painterly brush texture and nuanced soft volume matching richly illustrated rusty-orange junkyard buildings against blue sky. Clear readable natural asymmetric cumulus silhouettes, slightly flatter undersides, a mix of thin elongated clouds and fuller cloud clusters. Side-view game background art, not photorealistic, no heavy dark outline, no geometric flat ellipses. Actual alpha transparency everywhere outside clouds, no sky, no background gradient, no floor, no sun, no buildings, no characters, no text, no grid lines, no labels, no frame, no watermark. Each cloud should fill about 85% of its cell width and 65% of its cell height, with small feathery wisps and individually painted edges.
